## Getting Started

### Prerequisites

- A C++ compiler with C++11 support or newer (GCC, Clang, or MSVC)

### Compile

```bash
g++ -std=c++17 All_72_Problems.cpp -o all_problems
```

### Run

```bash
# Linux / macOS
./all_problems

# Windows
all_problems.exe
```

---

## How to Use

1. Open `ProblemSet60.pdf` to read the problem statements.
2. Find the matching solution in `All_72_Problems.cpp`.
3. Compile and run the program, then compare the output with the expected results.
